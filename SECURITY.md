# Security Policy

## Supported line

`console-automation-mcp-legacy@2.0.x` receives High and Critical security fixes for six months after the RunBeacon 3.0 Stable release. It receives no new protocols, features, compatibility work, or lower-severity fixes.

RunBeacon 3.0 and later are maintained in [Liyuchen0118/RunBeacon](https://github.com/Liyuchen0118/RunBeacon).

## Reporting

Report vulnerabilities through GitHub private vulnerability reporting for this repository. Do not include passwords, tokens, private keys, server addresses, command output, or other production secrets in a public issue.

## Release policy

Legacy releases require passing tests, dependency audit, and CodeQL review. Packages are published manually and never share the RunBeacon 3.0 Codex plugin ID.
